# 待选新增功能

以下为建议，尚未实现。回复编号即可选择，可多选。复杂度用于比较范围，不代表固定工期。

| 编号 | 功能 | 解决的问题 | 复杂度 |
|---|---|---|---|
| 1 | 真实历史回测与预警有效性评估 | 目前只有近似情景，不能证明评分能提前识别大跌 | 高 |
| 2 | 过热风险与下跌压力双评分 | 下跌中的负乖离和恐慌会降低旧评分，容易误解为安全 | 中高 |

| 5 | 模型配置方案管理 | 自定义权重与校准方案缺少便捷保存入口 | 中 |

## 1. 真实历史回测

按日重建可获得的因子序列，比较信号之后 20 / 60 / 120 个交易日的回撤、命中率、误报率和提前量。加入训练/验证区间，避免只挑选成功案例。

关键约束：历史分位数只能使用当日以前的观测；GDP等宏观数据需考虑公布日期及后续修订。无法获得历史读数的因子明确排除，不编造早期CNN情绪值。VOO上市之前不能直接使用VOO行情，替代指数需单独标注。

验收：同一配置可复现；无未来数据；输出每次警报与后续回撤的明细，以及不同阈值的误报比较。

## 2. 双风险评分

保留现有过热指标，另设下跌压力评分，结合峰值回撤、跌破长期均线、实现波动率与信用恶化。面板同时显示“潜在过热”和“正在承受的压力”，并解释主要贡献。

不会简单把现有低分直接反转；规则、权重和阈值需独立定义，并通过功能1评估。尽量使用已有价格/信用数据，避免无限增加相关指标。

验收：市场持续下跌时压力评分上升；过热和压力可以同时低、同时高或分别变化，不能误称为概率。

## 3. 定时采集与通知

增加不依赖浏览器的采集命令，支持交易日定时运行与持久化。通知仅在跨越阈值、风险级别变化、数据连续失效或恢复时触发，加入冷却时间与去重。

实施时再确定 Windows 计划任务或其他运行方式，以及用户选择的通知渠道。仅创建规则，不会未经授权向外部收件人发送消息。

验收：页面关闭仍能记录；相同警报不重复推送；非交易日与失败数据不伪造新的市场观测。

## 4. 收益率曲线状态

获取历史 10Y-2Y 序列，识别正常、倒挂、持续倒挂与倒挂后恢复；显示倒挂持续时间及恢复日期。

与当前“平坦曲线=经验高分”规则分开比较，并按模型版本保存，避免历史趋势混用旧规则。

验收：普通平坦曲线不被误判为解挂；状态转换有历史日期证据；获取失败时明确回退到当前规则。

## 5. 模型配置方案管理

保存、切换和恢复命名权重方案，例如默认研究、信用优先或估值优先。只针对VOO，不扩展监测标的。

验收：切换方案不混写历史，归一化后相同配置可以复用趋势；参数保存不包含FRED密钥。

## 6. 数据源容灾

为ETF行情加入符合用途和授权条件的备用来源；保存最近一次有效数据与原始观测日期。网络失效时可展示旧快照，并突出过期状态和各指标的时间差。

备用来源必须统一复权、单位、时区和交易日口径。GuruFocus无法访问时，优先考虑可验证的上市总市值口径，不以非金融权益代理冒充。

验收：模拟主源限流能进入正确备用链；旧快照不冒充新数据、不写成当天历史；不同来源的口径能核对。

## 7. 导出研究快照

导出CSV/JSON与可阅读报告，包含输入值、观测时间、来源、权重、模型版本、覆盖率、贡献及共振/红线调整。支持对比两个日期的变化原因。

验收：导出能复核页面分数；不包含密钥；缺失或手动值有标记；报告可以离线查看。

## 推荐顺序

若目标是研究模型是否有效，先选 **1**，再选 **2 / 4**。

若目标是日常稳定监测，先选 **6**，再选 **3**。

若主要改善使用体验，选 **5 / 7**。功能1和6是两类目标各自的基础。
